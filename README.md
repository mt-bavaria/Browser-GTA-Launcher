Willkommen beim GTA Launcher!

Mit diesem Launcher kannst du Bayday.io starten, Server beitreten und deine eigenen Server verwalten.

## 📥 1. Launcher herunterladen

1. Öffne das GitHub-Repository.
2. Klicke auf den grünen Button **Code**.
3. Wähle **Download ZIP**.
4. Warte, bis der Download abgeschlossen ist.

## 📦 2. ZIP-Datei entpacken

1. Öffne deinen Download-Ordner.
2. Suche die Datei `Browser-GTA-Launcher-main.zip`.
3. Klicke mit der rechten Maustaste darauf.
4. Wähle **Alle extrahieren**.
5. Wähle einen Speicherort aus.
6. Klicke auf **Extrahieren**.

## 🖥️ 3. Desktop-Verknüpfung erstellen

Damit du den Launcher bequem starten kannst:

1. Öffne den entpackten Ordner.
2. Suche die Datei `GTA_in_Browser.bat`.
3. Klicke mit der rechten Maustaste auf die Datei.
4. Wähle **Weitere Optionen anzeigen** (falls erforderlich).
5. Wähle **Senden an → Desktop (Verknüpfung erstellen)**.

Jetzt befindet sich eine Verknüpfung auf deinem Desktop.

## 🚀 4. Launcher starten

1. Gehe auf deinen Desktop.
2. Suche die Verknüpfung **GTA_in_Browser**.
3. Doppelklicke darauf.
4. Der GTA Launcher startet!

## 🎮 Funktionen

Der Launcher bietet folgende Funktionen:

- Offline spielen
- Server beitreten
- Server mit Freunden
- Eigene Server speichern
- Gespeicherte Server verwalten
- Server löschen
- HTTPS-Links kopieren

## ⚙️ Voraussetzungen

- Windows 10 oder Windows 11
- Internetverbindung

## 📌 Hinweise

- Entpacke die ZIP-Datei vollständig, bevor du den Launcher startest.
- Verschiebe oder lösche den entpackten Ordner nicht, solange du die Desktop-Verknüpfung verwendest.
- Der Launcher benötigt eine Internetverbindung, um Bayday.io zu öffnen.

Viel Spaß mit dem GTA Launcher! 🚀
